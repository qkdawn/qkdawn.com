Optional full TTF sources for `fonts.py` regeneration.

Expected filenames (from Google Fonts / OFL):

- `Inter[opsz,wght].ttf`
- `NotoSansSC[wght].ttf`
- `NotoSerifSC[wght].ttf`
- `InstrumentSerif-Regular.ttf`

Do not commit large TTFs to this repo; `site/fonts/*.woff2` are already subset and committed.
